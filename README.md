# NumberGuessingGameCMPSC132
Number Guessing Game - CMPSC 132 Final Project

Project Description: My project is the “Number-Guessing Game” – a single-player, terminal-style game. In my project, the computer randomly creates an integer from 1 to 100, and the user has a certain number of attempts to guess the target number correctly. The computer first prompts the user for a name and gameplay difficulty. The difficulty determines the max number of guesses, which ranges from 5 to 11. Then, the user starts the game, and the computer creates the random integer. Each time a user guesses, the computer tells the user whether their guess was too high or too low. If the user enters an invalid input, the terminal will ask them to enter a valid input, and it will not proceed until the user does so. Additionally, the user’s previous guesses and the number of attempts they have left also appear. If the user guesses the number correctly, they are prompted with congratulations as well as a leaderboard of their scores. If the user is unable to guess the target integer correctly in the number of attempts provided, they are prompted with a game over screen that also displays the target number. Win or lose, the game then prompts the user to play again, starting back with the name and difficulty selecting page.

Instructions to Play: An integer 1-100 is randomly generated, and you have a certain amount of tries to guess it correctly. Start by running the code, and you will be prompted to enter your name and difficulty. Then, begin guessing the number.

Good luck! Have fun!
